# VaultCall React Frontend

Vite + React frontend configured to connect with the live VaultCall backend on Render (`https://vault-backend-t9nu.onrender.com`).

## Setup & Run

```bash
npm install
npm run dev
```

## Environment Variable

`.env` and `.env.example` already include:

```env
VITE_API_URL=https://vault-backend-t9nu.onrender.com
```
